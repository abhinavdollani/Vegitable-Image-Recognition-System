# Vegetable Image Recognition System

An AI-powered vegetable image classification system built using Python and TensorFlow.

## Features

- Recognizes different vegetables from images
- Uses Convolutional Neural Network (CNN)
- Image preprocessing and normalization
- Data augmentation
- Model training and validation
- Prediction with confidence score

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pillow
- Streamlit

## Vegetables

The current model supports:

- Carrot
- Potato
- Tomato
- Brocalie
- Cabbage
